# PROJET ORION — Source C++

Ce dossier contient le code C++ du jeu développé avec Unreal Engine 5.

## Modules prévus

- OrionCore : fonctionnement général du jeu
- OrionGalaxy : univers et systèmes stellaires
- OrionPlanets : planètes et colonies
- OrionResources : ressources et constructions
- OrionFleets : vaisseaux et missions
- OrionExploration : exploration planétaire
